# Roadmap — Draft 0.9

## Phase 0 — repository foundation

Design baseline, CI, dependency lock, D1 dev database, regression fixtures.

## v0.1 — deterministic manual evaluation

NormalizedPC, CPU/GPU lookup, general/gaming laptop and desktop routing, manual price input, use-case evaluation, confidence/reasons/decision.

## v0.2 — URL analysis

Secure fetch boundary, JSON-LD/OpenGraph/generic parser, first retailer adapters, AI extraction fallback, missing-data flow.

## v0.3 — offer search and monetization

Merchant offers, frozen ranking, monetization resolver, outbound tracking and disclosure.

## v0.4 — own sales

“正二郎商事に探してもらう” lead flow with inherited evaluation context.

## v0.5 — replacement assistant

KEEP / UPGRADE / REPAIR / REPLACE and RAM/SSD/battery routes.

## v0.6 — selling assistant

Price range/confidence, sale-route recommendation and optional own buyback.

## v0.7 — gaming depth

Game profiles, gaming-laptop TGP/cooling/display depth and verified benchmark observations.

## v0.8 — market refresh

Scheduled observations, Queue pipeline, outlier handling and freshness metrics.

## v0.9 — revenue/quality dashboard

Funnel, category contribution, parser failures and scoring regressions.

## v1.0 — integrated launch

Purchase / replace / sell integrated with reliable fallbacks and operational documentation.
